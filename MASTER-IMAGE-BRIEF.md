# MASTER IMAGE BRIEF — 23 images, generated in sequence

## INSTRUCTIONS

You are producing the complete image set for one luxury gold jewellery website.
Follow this procedure exactly.

1. **Work through IMAGE 01 to IMAGE 23 in order.** Do not reorder, do not skip.
2. **Generate exactly ONE image per turn.** Never combine several images into one
   picture, and never produce a grid, contact sheet or collage.
3. Use the prompt under `PROMPT` **verbatim**. Every prompt repeats the full style
   description on purpose — do not shorten it, and do not substitute "same style as
   before". Reusing the earlier wording is what keeps all 23 images consistent.
4. Respect the stated `ORIENTATION` for each image: `portrait` or `landscape`.
5. After generating an image, check it against its `VERIFY` line. If it fails,
   **regenerate that same image** before moving on. State briefly what was wrong.
6. After each accepted image, print exactly one line:
   `DONE nn/23 — <filename>`
   then continue straight to the next image **without waiting for confirmation**.
7. If you cannot continue for any reason, print `STOPPED AT nn/23` and say why, so
   the run can be resumed from that number.

Do not ask questions before starting. Begin with IMAGE 01.

### Why every image lists its own style block

These 23 images sit next to each other on the same pages. If the background tone,
the gold tone or the lighting drifts between them, the set reads as photographs of
several different shops. Repeating the constraints on every image is what prevents
that drift over a long run.

### Filenames

Each image has a fixed filename, given as `SAVE AS`. Keep them exactly — they are
referenced by the website's code.
